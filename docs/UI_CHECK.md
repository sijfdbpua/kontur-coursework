# Проверка в браузере 19 ноября 2026 года

На одном компьютере запущена отдельная копия приложения с сервером Waitress и временной SQLite-базой. В ней находились 12 демонстрационных заявок до проверки. Два независимых контекста Google Chrome 157.0.8103.78 имели отдельные cookie. Диспетчер работал в окне 1440 × 960, техник — в мобильном представлении 390 × 844 CSS-пикселя с масштабом растеризации 2. Клиенты обращались к серверу через локальный адрес 127.0.0.1.

| Действие | Наблюдение |
|---|---|
| Диспетчер зарегистрировал проблему проектора и назначил техника | В базе появилась заявка № 13, исполнитель Михаил Волков. Техник увидел её после автоматического обновления своей очереди. |
| Техник начал работу и добавил комментарий | Карточка перешла в состояние «В работе», текст комментария появился в истории. |
| Техник описал результат и завершил работу | На его экране появился статус «На проверке». Диспетчер получил уведомление об изменении открытой карточки. |
| Диспетчер перечитал карточку и подтвердил результат | В списке появилась метка «Закрыта». Контрольное чтение API вернуло `status=closed`, `version=5`, восемь событий, исходный текст комментария и итог работ. |
| Техник выбрал показатель «Назначены» | Открылся фильтр назначенных задач. В списке статусов каждый пункт имел собственное значение. |
| Диспетчер вышел и в том же окне вошёл другой пользователь | Строки предыдущего пользователя удалены. Для дополнительной проверки пустого состояния автоматизация подставила ответ со списком `[]` только при втором входе. Появилось сообщение о пустой очереди. |

Во время сценария Chrome не зарегистрировал необработанных исключений JavaScript. В мобильной карточке ширина документа и окна составила 390 CSS-пикселей. По завершении сохранены [обзор диспетчера](../report/screens/desktop.png) и [карточка техника перед завершением](../report/screens/mobile.png). На втором снимке видны введённый результат и кнопка завершения.

Физический телефон и соединение через Wi-Fi требуют отдельной проверки на месте. Для неё предусмотрен [сценарий для двух устройств](TWO_DEVICES.md).
