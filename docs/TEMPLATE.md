# Оформление пояснительной записки

Для записки использован класс Калитвина В. А. из каталога XeLaTeX, коммит от 6 ноября 2026 года. [Исходный шаблон, коммит 0cb9ed3](https://github.com/kalitvin/tim_coursework_template/tree/0cb9ed33d958bd22d60ac172310717936e06c196/XeLaTeX).

В локальной копии timcw.cls сохранены структура титула, формат A4, поля 30/10/20/25 мм, основной кегль 14 и полуторный интервал. Для переносимости PT Serif / PT Sans / PT Mono и Menlo заменены на Liberation Serif / Sans / Mono. Добавлен вывод уже предусмотренного полем cwstudent ФИО: в исходном классе оно сохранялось, но не печаталось.

Направление и профиль взяты из образца преподавателя; ФИО, курс и группа сообщены студентом. Точная форма написания группы сохранена по сообщению. Сведения о руководителе, регистрации, подписи, оценка и дата защиты оставлены для фактического заполнения.

В титульном листе отрегулированы вертикальные интервалы, чтобы ФИО, поля комиссии и строка «Москва 2026» помещались на одной странице. Для введения, заключения и приложений поправлена привязка строк содержания к страницам заголовков.

Основная версия для печати — [PDF из XeLaTeX](../report/main.pdf). Исходник находится в [main.tex](../report/main.tex). Чтобы пересобрать его при установленных XeLaTeX, шрифтах Liberation и поддержке русского языка, выполни из корня проекта:

```bash
cd report
xelatex -halt-on-error main.tex
xelatex -halt-on-error main.tex
```

Для редактирования в текстовом процессоре есть [версия Word](../report/Курсовой_проект.docx) и [её экспорт в PDF](../report/Курсовой_проект.pdf). Разбиение на страницы зависит от программы вёрстки.
