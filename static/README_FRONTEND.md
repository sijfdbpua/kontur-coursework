# Интерфейс «Контур»

Локальные HTML, CSS и JavaScript без сборки и внешних CDN. Вход: `/`; стили, сценарий и иконка: `/static/…`. Серверный API описан в корневой документации проекта.

Диспетчер получает все заявки, поиск и фильтры, показатели на основе фактического списка, создание, назначение, изменение приоритета, проверку результата, закрытие и повторное открытие. Техник получает назначенные ему заявки, начало работы, ввод результата и передачу на проверку. Общие комментарии отображаются в истории.

Обновление списка — каждые 5 секунд, пока вкладка видима. При обнаружении новой версии открытой заявки показывается предупреждение: карточка не перерисовывается автоматически, чтобы не потерять ввод и фокус. Пользователь явно обновляет карточку; черновик комментария переносится. Сервер дополнительно проверяет версию при PATCH и возвращает 409. Сбой сети не очищает форму; индикатор связи меняется.

Динамический текст экранируется перед включением в шаблоны. Нет inline-обработчиков, inline-стилей или удалённых шрифтов. Ролевые элементы интерфейса не заменяют серверную проверку прав. Cookies отправляются только same-origin, CSRF-токен получается из `/api/session` и передаётся в каждом изменяющем запросе, включая вход.

Интерфейс адаптируется к телефону: боковая навигация становится верхней строкой, список заявок — карточками, подробная заявка занимает весь экран. Нативные dialog обеспечивают модальность, удержание фокуса и Escape. Все поля имеют подписи, кнопки — текст или aria-label. Демокнопки только заполняют поля, вход остаётся явным действием.

Ограничения: автономная работа без сервера не заявляется; установка PWA и push-уведомления не реализованы. Две вкладки одного браузерного профиля разделяют cookie; для разных ролей используй отдельные устройства или отдельные профили/контексты браузера.
